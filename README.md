# Simple Interest Calculator

A calculator that calculates simple interest given principal, annual rate of interest and time period in years.

## Project Details
- **Project Name:** Simple Interest Calculator (`github-final-project`)
- **Repository:** https://github.com/Rp-13-byt/github-final-project
- **Author:** Rp-13-byt
- **Organization / Course:** IBM Developer Skills Network - Introduction to Git and GitHub

## Input:
```
p, principal amount
t, time period in years
r, annual rate of interest
```

## Output:
```
simple interest = p * t * r / 100
```

## How to Run:
```bash
chmod +x simple-interest.sh
./simple-interest.sh
```
